# Reported historical results

These files transcribe Tables 1–3 and the trajectory disagreement count from James Chen's original final paper. They are **not outputs of a restored training run**.

- `results.json`: all tables, source attribution, and selection disagreement.
- `overall.csv`: benchmark correct/total counts and reported percentages.
- `math500_subjects.csv`: all seven subjects.
- `math500_levels.csv`: all five difficulty levels.

Counts are the authoritative values for new calculations. Displayed original percentages are rounded; percentage changes calculated from raw counts may differ slightly from subtraction of rounded table entries. Both MATH-500 breakdowns sum to 500 questions and 231/232 correct answers. Raw predictions and uncertainty scores were not recovered.
